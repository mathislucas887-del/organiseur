Bella Vita pour Android

L'application (APK v3.2) ouvre votre organiseur synchronisé avec le serveur : vos données restent enregistrées même si l'app est fermée ou le téléphone en veille.

Installer sur Android

  1. Touchez Télécharger l'APK, puis ouvrez le fichier organiseur.apk depuis les notifications ou l'app Fichiers.
  2. Si Android bloque l'installation : Paramètres → Applications → Accès spécial → Installer des applis inconnues, et autorisez votre navigateur (ou l'app Fichiers).
  3. Play Protect peut afficher « Application non reconnue » : touchez Plus de détails → Installer quand même. C'est normal pour une app installée hors Play Store.
  4. Au premier lancement, l'adresse du serveur est déjà remplie (https://organiseur.onrender.com) : touchez Continuer puis saisissez votre code PIN.
Le serveur gratuit se met en veille : le premier chargement peut prendre ~30 secondes.

Sur iPhone

Les APK ne fonctionnent pas sur iPhone. Ouvrez organiseur.onrender.com/app dans Safari, touchez Partager → Sur l'écran d'accueil.
